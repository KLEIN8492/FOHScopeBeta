# FOHScope v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS real-time FOH analyser: MTW spectrum + RTA, spectrograph, feedback finder, calibrated SPL with logging, A − B delta trace, for 1–16 user-added inputs.

**Architecture:** JUCE app, one process. Audio callback copies device channels into per-channel SPSC FIFOs; an analysis thread runs all DSP per input and publishes a `Frame` through a `TripleBuffer`; spectrograph columns go through their own FIFO; the UI repaints at 60 Hz from the latest frame.

**Tech Stack:** C++20, JUCE 8.0.15 (local copy at `../LiveRack/External/JUCE`, FetchContent fallback), Catch2 v3.7.1 (local copy at `../VenueTuner/engine/build/_deps/catch2-src`, FetchContent fallback), CMake ≥ 3.22.

**Spec:** `docs/superpowers/specs/2026-10-09-fohscope-design.md`

**Execution note:** executed inline by the author in the same session, so steps give the interfaces and exact test assertions; the code itself lands in each task's commit.

## Global Constraints

- macOS 13+ deployment target, universal-capable CMake.
- Namespace `fs`. No allocation, locks or logging on the audio thread.
- Levels internally in dB re full-scale RMS (`10·log10(ms)`); dBFS shown to the user = AES17 (+3.01 dB, full-scale sine = 0 dBFS).
- Grid: 480 points, `f_i = 20·2^(i/48)`.
- Inputs: min 1, max 16. Colours: golden-angle hue steps.
- Settings in `~/Library/Application Support/FOHScope/settings.xml`, logs in `.../FOHScope/levels/`.
- Local git only.
